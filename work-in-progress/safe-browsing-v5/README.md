# Inactive Safe Browsing v5 draft

This directory preserves unfinished Security implementation and test files.
Every source filename has a final `.txt` suffix so it is not compiled, bundled,
linted as code, or collected as an active test. Relative paths mirror the project.

These files are reference material, not a working feature. No API key is included.
Do not restore or enable them automatically. Read
`../../docs/SAFE_BROWSING_STATUS.md` before resuming.
