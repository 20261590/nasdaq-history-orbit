# Share 분리 인수인계

## 현재 상태

Share는 **NOT IMPLEMENTED**입니다. 현재 `src/features/share/SharePanel.vue`는 닫기 동작과 상태 안내만 렌더링합니다. 압축 URL, QR 코드, PNG, 미리보기, 공유 링크 복원은 아직 없습니다.

기존 분석, 기간 비교, 활동 패턴, 개인정보 점검, 지구본 표시는 완료된 기능으로 유지됩니다. 과거 완료 Share 문서와 증거는 역사 기록입니다. 현재 작업 사양으로 읽으면 안 됩니다. 원본 전체 백업과 `RESTORE.md`는 저장소 외부의 로컬 백업에 있으며 GitHub에는 포함하지 않습니다. 백업은 일반 파일과 심볼릭 링크 12,437개를 검증했으며, 분리 전 기준은 단위 검사 306개와 E2E 검사 19개였습니다.

## 맡길 범위와 연결점

담당자는 `src/features/share/**`와 그 기능의 테스트만 편집합니다. App, core, Security, 설정, 기존 테스트는 직접 바꾸지 않습니다.

- `src/features/share/types.ts`의 `ShareInput`은 집계 전용 입력 계약입니다. `ShareArtifacts`는 미래 출력 계약일 뿐, 생성 구현은 없습니다.
- `SharePanel`의 `input`은 다이얼로그가 닫혀 있거나 로컬 분석이 없으면 `null`입니다. 로컬 분석에서 열렸을 때만 App이 만든 입력을 받습니다.
- App이 native dialog를 열고 닫으며, `buildShareInput(...)` 결과만 패널에 전달합니다. 헤더의 **결과 공유**와 개인정보 점검의 **공유 전 검토**가 같은 패널을 엽니다.
- `src/features/share/index.ts`가 모듈 진입점입니다. App 최초 진입의 fragment에 `v` 또는 `d`가 있으면 같은 다이얼로그를 엽니다. 현재는 복원 미구현 안내만 표시합니다. 담당자는 `SharePanel` 안에서 fragment를 검증하고 정규화한 요약을 복원·표시할 수 있어 App이나 분석 내부를 바꾸지 않아도 됩니다. 수신 데이터는 외부 입력이므로 크기·스키마·숫자 범위를 별도로 검증해야 합니다.
- Security가 URL 마스킹과 분석 제외, 공유 전용 제외를 모두 소유합니다. Share는 원본 URL, 제목, 토큰, 비밀번호, IP, hostname, domain, 개별 세션 시각을 받거나 다시 검사하면 안 됩니다.
- `buildShareInput`은 두 코퍼스가 이미 두 제외 정책을 거친 뒤에만 호출됩니다. 허용된 집계 필드를 명시적으로 복사합니다. 국가 분포는 고유 사이트 수이고 비교 요약의 국가는 이벤트 수입니다. 순위는 익명 집계만 사용합니다.

## 구현할 결과

이 범위 안에서 요약 URL, QR PNG, 결과 PNG, 미리보기를 구현합니다. `ShareArtifacts`에 맞는 출력과 사용자에게 보이는 실패 상태를 만드세요. 기존 Share 계약에 없는 전체 지구본 복원을 원한다면, 제공된 입력으로 복원 가능한 범위를 먼저 명시하고 안전한 복원 출력 계약을 제안해야 합니다. 공급되지 않은 원본 궤적이나 위치를 복원한다고 가장하면 안 됩니다.

`ShareArtifacts.url`은 압축 요약 링크, `qrPng`와 `resultPng`는 각각 QR 및 결과 이미지의 `Blob`입니다. 압축·직렬화 포맷과 버전, QR/PNG 생성기, 다운로드와 복원 UI는 담당자가 구현합니다. 현재 계약은 전송 포맷이 아니며 기존 v1/v2 스키마나 알고리즘은 포함하지 않습니다. 패키지와 잠금 파일의 기존 Share 관련 의존성은 팀원 개발 환경을 위해 유지했지만 현재 앱에서는 import하거나 번들에 포함하지 않습니다.

표현도 다음 한계를 지켜야 합니다.

- 기간은 UTC 일 단위이고 `endDayExclusive`는 포함하지 않습니다. 입력 기간이 비어 있으면 `null`입니다.
- 비교는 독립 비교 코퍼스입니다. 활동 수치는 이벤트 수이며 체류시간, 생산성, 실제 사용시간이 아닙니다.
- 외부 평판 검사기나 스캐너는 연결하지 않습니다.
- 기존 modal 스타일을 재사용합니다. 새 레이아웃을 만들지 않습니다.
