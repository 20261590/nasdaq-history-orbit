# 압축 공유와 복원

공유 서버가 없습니다. 새 링크는 `https://host/path/#v=2&d=BASE64URL` fragment에 전체 스냅샷을 넣습니다. fragment는 일반 HTTP 요청에 포함되지 않습니다. 링크를 가진 누구나 내용을 복원할 수 있으므로 암호화나 접근제어로 설명하지 않습니다. 이전 v1 링크도 읽을 수 있습니다.

## 기본 프라이버시

익명 모드가 기본입니다. 사이트는 `Site 1` 등의 별칭으로 바뀝니다. 원본 URL·경로·검색 쿼리·인증정보·제목·원본 ID·IP·hostname·domain은 포함하지 않습니다. 경로의 시각은 UTC 일 단위로 줄이고, 이벤트의 상대 순서만 보존합니다. 요일과 시간대의 전체 집계는 활동 패턴 분석을 위해 남습니다.

사용자가 **사이트 도메인명 포함**을 직접 선택하면 검증된 등록 도메인만 넣습니다. 경로, 제목, 검색어, IP는 이 경우에도 제외합니다. 익명 스냅샷을 다시 공유할 때 원래 사이트명을 복구할 수 없으므로 이 옵션은 비활성화합니다.

집계 분포, 반복 방문과 지리 패턴으로도 개인을 추정할 수 있다는 경고를 공유 전에 표시합니다. 공유는 자동으로 일어나지 않습니다.

## 버전 2 스키마

Deflate 전 JSON의 필드:

| 키 | 의미 |
| --- | --- |
| `v` | 스키마 버전 2 |
| `a` | 0 익명, 1 도메인 포함 |
| `m` | 1이면 MOCK 데이터에서 생성됨. 복원 후에도 출처 유지 |
| `p` | 재생 속도 0.5, 1, 2, 4. 이전 v1 페이로드 누락 시 1 |
| `t`, `u` | 전체 방문 건수, 생략한 경로 이벤트 건수 |
| `b` | 분석 시작·종료일, Unix epoch부터 UTC 일 수 |
| `n`, `r` | 위치 확인 사이트 수와 확인률 |
| `s` | 사이트 사전: `[표시명, 전체 방문 건수, 비중]` |
| `w`, `h` | 요일 7개, 시간대 24개 집계 |
| `c`, `k` | 국가별·한국 지역별 고유 사이트 분포 |
| `l` | hostname별 `[사이트 인덱스, 상태 코드, 위치 배열]`. 원래 hostname 문자열은 저장하지 않음 |
| `q` | `[사이트 인덱스, 시작일 대비 일 오프셋, 이전 방문 대비 순서 차이, l의 호스트 인덱스]` |

상태 코드는 0 위치 확인, 1 실패, 2 미조회입니다. 위치는 `[위도×100, 경도×100, 국가, 국가코드, 정확도반경km 또는 null, 지역 또는 null, 도시 또는 null]`입니다. 반올림한 좌표는 약 1 km 수준의 표현 정밀도이며 GeoIP 정확도를 높여 주지 않습니다.

복수 hostname은 등록 도메인이 같아도 서로 다른 익명 호스트 행으로 저장합니다. 각 방문은 정확히 그 호스트 행을 가리키므로 같은 사이트의 한국·미국 위치와 위치 미확인 서브도메인을 혼동하지 않습니다. 사이트 통계는 등록 도메인 기준으로 유지합니다. IP 자체와 조직·ASN은 공유에서 제외합니다. 별칭은 `Site 1`, `Site 1 Host 2`처럼 원래 hostname을 드러내지 않습니다.

v1은 위치를 사이트 단위로 합쳐 저장하므로 원래 hostname별 연결을 복구할 정보가 없습니다. 원래 통계와 위치를 유지해 읽되, UI에서 한계를 알리고 불확실한 아크는 그리지 않습니다. v1 화면에서 다시 공유할 때도 전환 사이 간격을 남겨 확인할 수 없는 연결을 v2에서 다시 만들어내지 않습니다.

## 압축과 손실

반복 사이트를 사전 인덱스로 바꾸고, 시각·순서를 델타로 저장한 뒤 fflate Deflate와 Base64URL을 적용합니다. 전체 URL 상한은 2,800자입니다. 초기 경로 샘플 상한은 512건이고 길이가 초과되면 단계적으로 줄입니다. 인접 방문 쌍을 골라 실제 전환을 남기고 원래 순서 차이를 보존해 빠진 구간을 연결하지 않습니다.

표본에 포함한 hostname의 복수 IP 위치와 미확인 상태를 함께 보존합니다. 전체 통계는 표본으로 재계산하지 않습니다. UI는 포함한 경로 건수, 생략 이벤트 수와 경로에서 빠진 사이트 수를 표시합니다. 표본에서 빠진 사이트·호스트의 지도 상세가 없어질 수 있으므로 원본 지구본의 모든 마커를 보존한다고 보장하지 않습니다. 전체 집계만으로도 길이를 넘으면 명확한 오류를 반환합니다. 서버 저장으로 우회하지 않습니다.

2,800자는 QR의 최대 용량 근처에 있을 수 있으며 실물 카메라 인식률을 보장하지 않습니다. `createShareQr()`는 H → Q → M → L 순서로 실제 용량이 허용하는 가장 높은 오류 정정 수준을 선택합니다. PNG는 여백 4모듈과 **모듈당 정확히 4픽셀**로 생성합니다. UI는 최대 384px로 확대하고 밀도가 높은 QR에 원본 PNG·링크 복사 안내를 표시합니다. 작은 화면의 실제 크기는 가용 폭에 맞춰 줄어듭니다.

자연 생성 fixture의 전체 URL 길이 278/498/1,001/1,977/2,781자에서 압축 복원과 QR 디코딩을 확인했습니다. 정확한 500/1,000/2,000/2,800자 경계는 같은 유효 페이로드에 짧고 무의미한 query padding을 사용해 별도로 검사하며, 압축 크기 개선으로 오인하지 않도록 padding 수를 기록합니다. 기준·실제 측정은 `docs/evidence/phase2/qr-matrix.json`과 `qr-boundary-*.json`에 있습니다.

## 입력 보안

- 인입 fragment 최대 12,000자.
- Deflate 해제 후 최대 256 KiB. 스트리밍 Inflate를 32바이트 압축 청크로 처리하고 제한을 넘는 즉시 중단합니다.
- Zod strict schema: 알 수 없는 키, 잘못된 버전, 음수/무한/NaN/안전 정수 범위 밖 수, 범위 밖 위도·경도, 잘못된 참조와 순서, 역전된 기간, 비일관된 방문 건수를 거부합니다.
- 좌표는 위도 ±90°, 경도 ±180°입니다. 시각 범위는 JavaScript Date의 유효 범위를 넘지 않습니다.
- 반경은 0 이상의 유한 실수를 허용합니다. `St. John's`, `Côte d’Ivoire`처럼 공급자가 제공할 수 있는 이름의 구두점도 보존하며 HTML로 실행하지 않습니다.
- 복원 오류는 화면에 표시합니다. 외부 DNS·GeoIP 재조회나 원본 업로드를 자동 실행하지 않습니다.
- 문자열은 Vue의 안전한 텍스트 출력만 사용합니다. 페이로드를 스크립트나 HTML로 실행하지 않습니다.

QR 픽셀을 실제로 해독해 URL과 일치하는지 확인하는 테스트와, 새 탭에서 동일 통계와 마커를 복원하며 공급자 요청이 0건인지 검사하는 테스트가 `tests/e2e/orbit.spec.ts`에 있습니다. 실제 휴대전화 카메라 촬영 결과와 브라우저 모바일 에뮬레이션 결과는 검증 문서에서 구분합니다.

공유 미리보기에는 집계와 실제 좌표·국가·지역·도시·반경이 드러납니다. 사이트명 포함을 선택하면 공개할 도메인 목록도 모달에 표시합니다. 원본 URL·제목·검색어·IP를 제외하는 것과 위치·활동 패턴까지 비공개인 것은 다릅니다.
