# History Orbit

브라우저 방문기록과 추정 위치를 지구본에서 보고, 기간 비교·활동 패턴·개인정보 노출 가능성을 분석하는 정적 웹 애플리케이션입니다. Share는 현재 **NOT IMPLEMENTED** 상태입니다. 기존 분석 기능은 유지되지만 익명 링크, QR, PNG, 공유 복원은 제공하지 않습니다.

## 실행

Node.js 22.12 이상 또는 Bun이 필요합니다. 이 프로젝트는 Bun으로 검증합니다.

```sh
bun install
bun run dev
```

표시된 localhost 주소를 엽니다. JSON을 업로드하거나 **예제 데이터로 둘러보기**를 선택하세요. 예제의 위치는 합성 MOCK 데이터이며 실제 DNS 결과와 구분됩니다.

```sh
bun run typecheck
bun run lint
bun run test
bun run test:performance
bunx playwright install chromium firefox webkit
bun run test:e2e
bunx playwright test --config playwright.integration.config.ts
bun run build
bun run preview
```

## 사용 흐름

1. JSON 파일을 선택하거나 드래그합니다. 파일은 기기 안에서 읽습니다.
2. 원본 유효·제외·중복 건수와 로컬 개인정보 검사를 확인합니다. URL의 민감한 값은 기본으로 가립니다.
3. 실제 위치 공급자를 선택하고 외부 조회에 동의합니다. Google에는 hostname, GeoJS에는 공용 IP만 전송합니다.
4. 마커와 현재 방문을 확인하고 재생, 탐색, 기간·국가 필터를 사용합니다.
5. **분석과 개인정보 점검**에서 입력의 마지막 관찰일 기준 7일·30일·월별 또는 직접 지정한 A/B 기간을 비교하고 활동 세션 기준을 조정합니다. 비교 기간의 지구본 연결은 반대편 비교 기간을 지우지 않습니다.
6. **분석에서 제외**는 통계와 향후 Share 입력 모두에, **공유에서만 제외**는 향후 Share 입력에만 적용됩니다. **결과 공유**와 개인정보 점검의 **공유 전 검토**는 현재 Share 안내 패널을 엽니다.
7. Share의 URL·QR·PNG 생성과 공유 링크 복원은 팀원 개발 및 통합 예정입니다.

통합 브라우저 검사는 일반 프로덕션 빌드를 로컬 정적 테스트 서버에서 열어 루트와 `/__integration_qa__/` 하위 경로의 업로드·로컬 분석을 함께 검사합니다. 이 서버는 테스트에서만 실행되며 배포 산출물에는 포함되지 않습니다. Chromium·Firefox와 모바일 프로필의 Chromium·WebKit을 사용하며 실제 휴대전화 하드웨어 검증을 대신하지 않습니다. 이번 분리 작업의 실제 실행 범위와 결과는 `docs/evidence/share-separation/`에 기록합니다.

위치 조회 전에도 통계가 표시됩니다. 위치 미확인 사이트를 통계에서 제외하지 않습니다. 일부 조회가 실패하면 취소하거나 미확인 항목을 다시 시도할 수 있습니다.

재생은 **방문 선택 → 위치 확인 → 비행 → 실제 도착 → 관찰 → 다음 방문** 순서로 진행합니다. 카메라가 목적지에 도착해 멈추고 최소 2초를 관찰하기 전에는 다음 방문으로 넘어가지 않습니다. 5,000 km 이상 이동한 뒤에는 2.5~3초를 관찰하며 마지막 방문도 관찰을 마친 뒤 종료합니다. 위치가 없는 방문은 현재 화면을 유지하며 미확인 정보를 2초 표시합니다.

자동 비행시간은 대권거리에 따라 아래 기준점 사이를 연속적으로 보간합니다. 표는 1× 기준이며 동일 좌표에는 비행을 만들지 않습니다.

| 이동 거리 | 비행시간 |
| --- | --- |
| 500 km 미만 | 2~3초 |
| 500~2,000 km | 3~4초 |
| 2,000~5,000 km | 4~6초 |
| 5,000~10,000 km | 6~8초 |
| 10,000 km 이상 | 8~10초 |

도시·지역 시야를 유지하며 가속·순항·감속합니다. 가까운 위치에서는 줌을 유지하고 장거리에서만 시야를 넓혔다가 목적지에서 다시 확대합니다. 화면에 `대기`, `가속`, `순항`, `감속`, `목적지 관찰`, `일시정지`, `수동 조작` 상태와 진행률을 표시합니다. 원본 방문 시각과 시각적 재생 시간은 별개입니다.

속도 배율은 비행에만 적용합니다. 관찰 시간은 4×에서도 줄어들지 않습니다. 일시정지는 비행과 관찰 시계를 함께 멈추고 같은 지점에서 재개하며, 속도 변경과 재개는 0.5초의 부드러운 배율 전환을 사용합니다. 드래그·휠·터치 조작은 자동 재생을 멈추며 사용자가 다시 재생하거나 탐색하기 전에는 복귀하지 않습니다. 직접 타임라인을 탐색하면 기존 비행을 취소하고 선택한 위치로 한 번 이동합니다. 이 명시적 탐색과 `전체 지구`·`대한민국 확대`의 화면 전환은 기존 3.5초 방식을 유지합니다. 화면 밖이나 숨겨진 탭에서는 모션 시계가 진행하지 않습니다.

대량 기록은 기존 최대 800건 순서 샘플링과 기간 필터를 사용합니다. 원본 순서가 연속임을 확인한 같은 hostname 구간만 묶고, 묶음 건수와 원래 시각 범위를 표시합니다. 서로 다른 사이트가 같은 좌표에 있어도 정보를 별도로 관찰합니다. 통계와 원본 timestamp는 줄이지 않으며 샘플 간격이나 미확인 위치를 가로지르는 아크를 만들지 않습니다. 중요한 방문을 임의로 선정하거나 비행 중 목적지를 건너뛰는 요약 정책은 추가하지 않았습니다. 검증 결과와 계측 자료는 [모션 수락 보고서](docs/evidence/motion/acceptance.md)에 있습니다.

## 지원 데이터와 한계

- Google Takeout Chrome의 `Browser History` 배열과 `time_usec`.
- `url`과 `timestamp`, `lastVisitTime` 또는 `visitTime`이 있는 JSON 배열 및 `{ "history": [...] }`.
- 방문 시각은 ISO 문자열 또는 Unix 초·밀리초. Firefox/Edge 전용 내보내기 형식 전체를 지원한다고 보장하지 않습니다.
- 최대 파일 20 MiB, 최대 입력 100,000건. 통계는 유효 기록 전체, 재생은 최대 800건, 전체 경로는 최대 400개 아크, 좌표별 마커는 최대 1,500개입니다.
- 통계의 시각 기준은 UTC입니다. 방문 횟수는 체류시간이 아닙니다.
- Share 입력은 제외 정책을 거친 집계만 명시적으로 복사합니다. 원본 URL·제목·토큰·비밀번호·IP·hostname·domain·개별 세션 시각은 포함하지 않습니다. 국가 분포는 고유 사이트 수이며 비교 국가 수는 이벤트 수입니다.
- Share가 구현되기 전에는 QR URL 길이, PNG 다운로드, 사이트명 공개, 이전 공유 링크 읽기, 요약 복원이 제공되지 않습니다.

GeoIP 위치는 방문 당시 실제 서버나 물리 서버의 정확한 주소가 아닙니다. 현재 DNS, CDN, Anycast, GeoIP 오차를 포함한 추정입니다. 한국의 구 단위 위치를 좌표로 만들어내지 않습니다.

반경 미제공·25 km 초과 시 상세의 주 표시는 국가 수준으로 낮춥니다. 이 기준은 UI 정책이며 행정 경계 검증이 아닙니다. 향후 Share를 구현할 때도 요일·시간대·국가 집계가 개인을 식별할 수 있음을 고려해야 합니다.

첫 화면은 작은 정적 지구 미리보기를 사용하고, 분석 시작 후에만 3D·차트를 다운로드합니다. 데이터 절약·낮은 코어 수 또는 지속적으로 느린 프레임에서는 표시 해상도·곡선 분할을 낮추며 방문 통계와 마커 수는 유지합니다.

## 정적 배포

`bun run build`가 생성하는 `dist/` 전체를 정적 호스팅에 배포합니다. Vite `base: './'`로 하위 디렉터리 배포도 지원합니다. `index.html`, `assets/`와 같은 디렉터리의 `earth.webp`, `earth-preview.webp` 등 정적 파일을 함께 유지하세요. Cloudflare Pages, GitHub Pages 또는 일반 정적 웹서버에서 동작하며 별도의 애플리케이션 서버·서버리스 함수·API 프록시가 없습니다.

현재 공유 fragment 생성과 공유 링크 읽기는 구현되지 않았습니다. Share 구현도 서버 측 짧은 URL 저장 서비스는 추가하지 않아야 합니다.

RC의 실제 브라우저 행렬, 테스트 결과, 실기기 미검증 범위와 직접 점검 목록은 [Release Candidate 보고서](docs/RELEASE_CANDIDATE.md)에 있습니다. HTTPS·CSP·캐시·하위 경로 설정과 로컬 재현 절차는 [정적 배포 절차](docs/DEPLOYMENT.md)를 따르세요. 실제 원격 배포는 수행하지 않았습니다.

GitHub Pages는 [전용 설정 절차](docs/GITHUB_PAGES.md)를 따르세요. `.github/workflows/deploy.yml`이 실제 Pages 메타데이터로 사용자 페이지(`/`)와 프로젝트 페이지(`/저장소명/`)의 빌드 경로를 결정하고, 기본 브랜치의 검사·빌드 성공 후 `dist/`만 배포합니다. 저장소명·원격 주소는 임의로 설정하지 않았습니다.

## 개인정보

원본 JSON, URL 경로·쿼리·제목은 브라우저 메모리에서만 처리합니다. 쿠키, 로컬 저장소, 원격 DB, 추적 스크립트를 사용하지 않습니다. **새 분석**은 화면과 활성 분석 상태를 초기화합니다. JavaScript 메모리 회수 시점은 브라우저가 결정하므로 완전한 메모리 삭제를 보장하지 않습니다. 사용을 마치면 탭을 닫으세요. 외부 공급자는 자신의 API로 전송된 hostname/IP와 접속 IP를 볼 수 있습니다. Share는 현재 미구현이며, 향후 익명 공유를 구현해도 집계 패턴이 개인을 식별할 수 있음을 고려해야 합니다.

인증·비밀번호·세션 값과 이메일·전화번호·불투명 식별자 후보를 로컬 규칙으로 분류합니다. `id`, `code`, `key` 같은 이름만으로 위험을 확정하지 않으며, 후보 탐지는 유효한 자격 증명·실제 유출·악성 사이트 판정이 아닙니다. 방문 이벤트와 관측 세션 조각은 실제 사용시간·집중력·생산성·건강 진단을 뜻하지 않습니다.

평판 조회 서비스는 연결하지 않았습니다. 연동하려면 브라우저에 비밀 API 키를 노출하지 않는 공급자 계약, 허용된 CORS 출처, 요청 한도·비용, 전송 데이터와 별도 동의 정책을 먼저 정해야 합니다. 이를 충족하지 않은 자동 URL 전송이나 프록시는 추가하지 않습니다.
